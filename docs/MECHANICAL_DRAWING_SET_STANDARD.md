# Mechanical Drawing Set Planning Standard

## Mandatory pre-generation stage

Mechanical CAD generation must not start before Drawing Set Planning and user approval.

Flow:

Architecture Upload -> Mechanical Questions -> Scope Analysis -> Drawing Set Proposal -> User Approval -> CAD Generation

## Calculation principle

Total sheets are calculated as:

System Effective Levels + Roof Drawings + Riser/Diagram Drawings + Special Sheets

## Systems

- Cooling: one plan per effective conditioned level
- Heating: one plan per effective heated level
- Water Supply: one plan per wet/plumbing level
- Sanitary & Vent: one plan per sanitary level
- Ventilation: one plan per ventilation-required level
- Gas: one plan per gas-consumer level
- Roof Drainage: roof plan when required
- Riser: required when vertical systems exist

## Typical Floors

Identical mechanical patterns must be consolidated into Typical Floor plans instead of duplicate sheets.

## Approval Gate

The customer must review the proposed drawing list and approve it before design generation.
