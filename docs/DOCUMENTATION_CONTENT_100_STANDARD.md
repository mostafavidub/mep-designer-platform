# Details, Schedules, Notes and Legends — 100-point standard

Submission Ready output must pass all eighteen controls in
`cad_engine.documentation_content_gate`. The controls cover the project scope and
required-document matrix, governed executable details, calculation-derived
parameters, active-system and constructability coverage, model-derived equipment
and network schedules, cross-document identity, project-specific notes with
standards provenance, used-symbol-only legends, unique meanings, layout,
print readability, coordination, per-sheet QA and exact reopened-output parity.

Mechanical reference drawings are forbidden as generation inputs. Missing facts
remain `INPUT_REQUIRED`; contradictions are `FAIL`. Preflight may validate the
first seventeen controls but cannot authorize release. Submission Ready requires
all controls `PASS`, an exact score of 100, and evidence that every detail,
schedule, note and used legend symbol exists in the immutable issued DXF.

The gate does not invent design values or replace responsible-engineer review,
signature or stamp. Existing projects must be regenerated to receive this
additive evidence contract.
